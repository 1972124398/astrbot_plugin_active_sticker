# 主动表情

AstrBot 的表情包插件。让话少的角色偶尔贴一张，让会接梗的角色顺手回个表情。和熟人笑到停不下来，角色也可以一口气发几张，甚至故意重复同一张。

正文发送后，AI 先根据人格和对话决定自己是否想用表情、想表达什么。这个步骤看不到候选图片。决定想发之后，再按表达意图检索本地描述文档，由 AI 判断是否有足够贴切的图片。可以继续换词或换分类查找，也可以放下这次表情。

启用插件并准备好可用图片后，每轮对话会自动向 AI 注入能力说明：需要表情包时优先使用主动表情，正常回复后自动判断和选图，无需修改人格或在主对话调用工具。微信原生收藏与本地图库独立，原生收藏为空不影响本插件；用户明确要求原生收藏时仍可使用对应工具。插件关闭、当前会话未启用或没有可用图片时，不会注入这条优先使用说明。优先使用不代表每轮必发，是否表达及图片是否贴切仍由 AI 判断。

成功发送后，同一会话和人格的后续对话会收到图片描述和最初的表达意图，作为自己这轮回复的一部分。最近发送记录保存在插件数据目录，重载后可以接续。说明只供 AI 阅读，聊天里只发图片。

## 安装与建库

1. 在 AstrBot **插件 → 安装插件** 中粘贴 [本仓库地址](https://github.com/1972124398/astrbot_plugin_active_sticker)。支持 AstrBot 4.29.4 及以上的 4.x 版本。
2. 从插件详情打开**主动表情面板 → 设置**，选择支持图片输入的**识图模型**。留空时会查找已声明支持图片输入的聊天模型。**表情判断模型**留空时跟随会话模型，也可以单独选择。保存立即生效，AstrBot 原生插件配置也可编辑同一份设置。
3. 切换到面板的**表情库**。拖入或批量选中图片。识图模型可用时会自动生成「画面与语气」「适合怎么回」和「标签」。可以先导入，之后在面板选好模型时会接着处理待识别图片。支持 PNG、JPEG、GIF 和 WebP，单张最大 16 MB。同一文件重复导入会去重。
4. 看到「可使用」后，正常和机器人聊天即可。可搜索、预览、编辑、重试识图、停用或删除图片。图片也可以直接手填描述。动图识别会看多个代表帧，发送走平台的原图组件，动图的播放效果由平台适配器决定。

## 风格包与手动整理

面板顶部支持新建、重命名和停用风格包，例如「猫猫日常」「像素小人」。风格包按角色、画风或整套使用习惯手动划分；「开心、难过、调侃」等表达用途继续用于包内检索。每张图片属于一个风格包，识图不会更改人工指定的包。

- 已有图片自动归入「未分组」，图片和描述继续保留。可以先新建两个风格包，再勾选图片，批量移动到对应包；也可以在单图编辑里改包、名称、描述、标签和表达用途。
- 导入时选择目标风格包，新图片会自动归入。重复文件保留原来的归属，防止重复导入打乱人工整理。
- 支持按包、用途、状态、关键词共同筛选，以及批量启用、停用。停用整个包后，它不会参与新对话选包；删除包会把图片移回「未分组」，保留原图。
- 选中具体包后可「打包下载」ZIP，包含原图、完整描述与归属元数据 `pack.json`，便于备份与筛选。未识图、停用的图片也会打包；源文件缺失的条目保留元数据。目前 ZIP 用于导出备份，面板导入仍为图片文件。

每个会话和人格分别保持一个当前风格包，首次从有可用图片的包中等概率选择。**默认空闲满 6 小时后，下次对话有 50% 概率更换为另一个可用包**；没有换中就继续使用原包。每次空闲结束只判断一次，连续聊天更新活动时间并保持原包。设置里可调整空闲时长与更换概率；概率设为 100% 时，有其他可用包就必换，设为 0% 时保持原包。当前包被停用、删除或没有可用图片时，下次对话会重新选包。选择和活动时间在重载后保留。

从意图检索到每张图片发送，都限定在当前包内；AI 可以换词或换表达用途检索，找不到合适素材就不发，不会跨包凑图。风格包只约束图片素材，是否使用表情、想表达什么、连发几张继续由 AI 按人格和语境决定。

发送频率由 AI 根据人格和现场对话决定。可在**补充表情习惯**里写角色自己的习惯，例如「平时不怎么用图，只有笑场才发，朋友一起起哄时会重复两三张」。连发上限默认 6 张，可在配置修改，实际张数由角色在每轮判断。

## 导出图片列表与图库文档

面板表情库顶部提供三个文档导出入口，不受当前风格包、搜索、分类或状态筛选影响：

- **导出全库 CSV**：下载 `stickers.csv`，每张图片一行，包括文件名、图片 ID、原图相对路径、风格包及说明、表达分类、标签、画面与语气、适用场景、启用状态、源文件是否存在、识图状态和错误。停用、待识图和缺失图片同样保留。UTF-8 BOM 编码方便 Excel 直接打开中文。
- **导出图库文档 ZIP**：下载 `sticker-library-documents.zip`，包含上述 CSV、完整 `index.json`，以及插件生成的 `catalog.md`、`library.md` 和 `catalog/` 全部分类别描述文档。生成文档记录可用图片，CSV 和元数据记录完整图库。此包不包含原图，原图仍可在具体风格包中「打包下载」。
- **下载描述目录**：单独下载已有的 `catalog.md`，方便快速查阅。

从 1.5.0 起，每次成功识图还会保存当次自动生成的描述、适用场景、标签、分类、模型和 UTC 时间。CSV 将这些结果单独列出，人工修改当前描述或分类后仍可对照；再次识图成功会更新自动结果，失败则保留上一次成功结果。旧图库无法还原此前未保存的自动结果，对应列留空，现有描述与分类照常导出，无需为了导出重新调用模型。正在识图的图片保留导出瞬间的状态，可待识图结束后再导出。

CSV 中可能被表格软件识别为公式的文本前加单引号，避免打开时执行；`index.json` 保留原始文本。

## 可选联动

- **短期共享情绪**。读取会话允许访问的当前心情与表达倾向。模型可以把笑场、撒娇、假装生气等演成单张或连发，也可以让正文自己收尾。可以单独关掉。
- **自主认知**。主动表情可以参考同一会话的长期表达习惯。自主认知 0.10.2 起也可以在后台回顾时查看库中表情的含义和使用语境。双方分别可关闭。
- **独立使用**。表情库、识图和依人格发送可单独运行。仓库自带管理页，图片由管理员导入。

表情库数据放在 AstrBot 的插件数据目录内。面板可下载 `catalog.md`。插件间可按当前会话调用 `companion_sticker_catalog(origin)`，得到版本化的只读条目，包含 ID、名称、描述、用法和标签。

图片可标注开心、难过、生气、惊讶、尴尬、亲近、调侃、回应、日常等粗分类，也可以多选。面板支持按分类筛选和编辑。已有图片会依据描述与标签归入检索分类，新识图也会给出分类。

`library.md` 是简短的分类目录，`catalog/` 下按分类保存描述文档。分类和关键词只用于寻找素材，表达意图和图片是否贴切由 AI 决定。完整的 `catalog.md` 继续用于人工查阅与导出。

## 识图整理与节省选图 token

1.6.0 起，识图在保留完整描述的同时，另外整理「核心表达、真实语气、图中文字、误用限制」四个短字段。精简卡优先保留会改变含义的文字、反讽和限制，避免反复发送装饰细节。这些字段保存在自动识图结果中，并随 CSV 和文档导出。手动改变描述、用途、标签或分类后，检索改用当前人工内容，避免沿用失效的自动概括。旧图片直接使用已有文字建立索引，不需要重新识图；长文字保留首尾及单独的误用提示。

检索全部在本地完成：按标签、核心表达、画面说明、使用场景和文件名设置不同权重，对低频词加权并进行长度归一；中文同时匹配词片段和低权重单字，结合表达分类的常用近义线索召回。误用场景中的负面说明不作为正向用途索引。每包独立建立倒排索引与有界查询缓存，人工编辑或识图更新后自动重建；一批内合并描述及语气等内容完全相同的候选，保留文字不同的版本。

AI 仍先结合人格、对话与心情决定是否想发表情。确定意图后，选图请求只包含意图、短回复摘录、当前说话人、包内分类数量和一批精简卡，不再反复发送完整人格、聊天历史和联动状态。**每批最多 8 张，候选 JSON 不超过 2600 字符**，采用批次内短编号替代长图片 ID；字符预算不是精确 token 计数，实际用量随模型和文本变化。最多换词或换分类检索三批，已展示的图片不重复提供，相同检索请求会停止。没有合适素材时仍可不发，检索和最终发送继续限定当前风格包。

在表情库顶部点击 **整理检索索引**，即可手动触发全库后台重建，面板会显示整理状态、可用图片数、有效风格包数及更新时间。整理只读取已有识图与人工描述，**无需识图模型、不调用 AI、不消耗模型 token**，也不会移动图片或更改人工内容；缺少描述的图片仍需使用「识别待处理图片」。重复点击不会启动多个任务，整理期间发生编辑会丢弃旧快照并重试；图库持续变化时可稍后重试。

生成的 `retrieval-index.json` 记录精简卡、归属、表达分类和索引版本，可随「导出图库文档 ZIP」下载查看。这个文件是派生索引，重建不会覆盖原始图库元数据。

## 开发

基于 AstrBot 内置 AI 的消息事件和图片组件。普通回复在发送钩子触发表情判断，流式回复在平台交付后的完成阶段触发。微信等平台将图片作为图片消息送出。只支持走 AstrBot 回复事件的交流，像其他插件直接调用平台接口发送的消息不会触发附图。

```powershell
python -m pip install "astrbot==4.29.4" -r astrbot_plugin_active_sticker/requirements.txt
python -m unittest discover -s astrbot_plugin_active_sticker/tests -v
node --check astrbot_plugin_active_sticker/views/library/app.js
```
